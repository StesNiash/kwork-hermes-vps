# PORTFOLIO — Hermes Agent на VPS

## Кейс: чистый Ubuntu VPS → рабочий Telegram-агент

**Задача.** Поднять Hermes Agent на сервере, подключить Telegram и оставить владельцу понятную эксплуатацию.

**Ограничения.** Нельзя обещать «магию»: нужны ключ модели, bot token и SSH. Dashboard нельзя публиковать без TLS и пароля.

**Что сделано.**

- Установщик на Bash с проверкой ОС, Docker и compose.
- `.env` генерируется с правами `600`; секреты не попадают в git.
- Отдельные порты только на localhost; доступ через SSH-туннель.
- Healthcheck ждёт готовности gateway, а не просто `docker ps`.
- Smoke-check проверяет токен, compose, контейнер и API.
- Backup/restore с остановкой контейнера на время копирования.
- Опциональный Caddy-профиль для HTTPS.

**Результат.** Один сценарий установки, который можно повторить на другом VPS, и список ограничений, который снимает половину будущих претензий.

**Что осталось проверить.** Живой прогон на чистом Ubuntu 22.04 и 24.04 с реальным Telegram-ботом. До этого репозиторий считается demo-ready, но не production-proven.
